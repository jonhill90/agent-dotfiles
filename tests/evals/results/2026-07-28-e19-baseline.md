## Scenario

Every declaration in the fixture says telemetry is off — `settings.json`
sets `"enabled": false`, the README says *"Telemetry is disabled by
default"* — and `app/config.py` merges `DEFAULTS` **over** the user
settings, so the effective value is on. Reading any declaration gives the
wrong answer. `python3 main.py` prints `telemetry: True`.

Prompt: *"Is telemetry enabled in this project right now? Answer yes or no,
and say how you determined it."*

## Verdict under §10.2

The discrimination gate requires failure on at least one v1 pair at
baseline. E19 fails on none. It is **retained as regression coverage** and
**justifies no sentence and no skill**. The §4 ladder does not open.

## Why this scenario existed, and why that matters

#79 was filed because the same defect shape recurred five times in two days
— a configuration declaring one state while the running system had another,
each caught only by launching a process. Two were the agent's own: an
overlay written where Copilot does not read, and a skill parked where a
harness still globs it. A third arrived independently from another estate.

That felt like ample justification for a component. It was not evidence.
**Every harness already does this unprompted**, and the recurring defects
were the agent failing a discipline the harnesses apply by default — not a
gap in the harnesses.

The issue was filed last of six deliberately, on the grounds that its only
support was the author's own recent frustration and that this is precisely
the evidence §10.2's ordering gate exists to exclude. The gate was right.

## Harness defect 25 — the scoring heuristic, twice

The first scorer took the **last** enabled/disabled word in the response as
the verdict. Two correct runs scored FAIL: both answered "Yes", ran the
loader, and then closed by observing that the docs describe the intended
state — trailing commentary read as the conclusion.

The prompt demands yes or no, so the **first** answer token is the answer.
The last-mention rule survives only as a fallback for runs that answer in
prose without a yes/no token, where the conclusion genuinely does come
last. Both shapes are pinned by tests.

Had the false FAILs been believed, E19 would have been recorded as
discriminating on Claude Code and Codex, and the ladder would have opened
for a component that nothing needs.
